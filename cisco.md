CISCO SOFTWARE ENGINEER ROADMAP 🚀

Want to target Cisco?

Don't prepare like you're preparing for a generic SDE role.

Cisco heavily values:
Networking + Systems + Software Engineering.

Here's the roadmap I'd follow 👇

MONTH 1 - DSA + CS FUNDAMENTALS 🧠

WEEK 1–2 → DSA

Focus on:

• Arrays
• Strings
• Hashing
• Two Pointers
• Sliding Window
• Binary Search
• Linked List
• Stack / Queue
• Recursion
• Bit Manipulation

Resource:
NeetCode → [neetcode.io/roadmap](https://neetcode.io/roadmap)

WEEK 3 → TREES + HEAPS

• Binary Trees
• BST
• Heap / Priority Queue
• Top K
• BFS / DFS

Resource:
LeetCode → [leetcode.com](https://leetcode.com/)

WEEK 4 → GRAPHS + DP

• Graph BFS / DFS
• Shortest Path
• Topological Sort
• Union Find
• 1D / 2D DP
• Greedy

Target:

**60–70 quality problems in Month 1.**

Don't chase problem count.

Focus on recognising patterns.

MONTH 2 - NETWORKING + LINUX 🌐

This is where your Cisco preparation becomes different from generic SDE preparation.

WEEK 5 → NETWORKING FUNDAMENTALS

Learn:

• OSI Model
• TCP/IP Model
• MAC & IP addresses
• Ports
• Ethernet
• ARP
• ICMP
• DNS
• DHCP

Resource:
Cisco CCNA → [cisco.com/site/us/en/lea…](https://www.cisco.com/site/us/en/learn/training-certifications/exams/ccna.html)

WEEK 6 → TCP/IP + ROUTING

Learn:

• TCP vs UDP
• TCP 3-way handshake
• IPv4 / IPv6
• Subnetting
• CIDR
• NAT
• Routing tables
• Static vs Dynamic Routing
• OSPF
• BGP

Resource:
Cisco Networking Academy → [netacad.com](https://www.netacad.com/)

WEEK 7 → SWITCHING + SECURITY

Learn:

• Switch vs Router
• VLAN
• Trunking
• STP
• ACL
• Firewalls
• VPN
• Network Security

Resource:
Cisco Skills for All → [skillsforall.com](https://skillsforall.com/)

WEEK 8 → LINUX + SOCKET PROGRAMMING

Learn:

• Processes
• Threads
• Memory
• File systems
• Permissions
• Signals
• SSH
• Shell scripting
• Network debugging
• TCP sockets
• Client / Server architecture

Resource:
Linux Journey → [linuxjourney.com](https://linuxjourney.com/)

Socket Programming:
Beej's Guide → [beej.us/guide/bgnet/](https://beej.us/guide/bgnet/)

MONTH 3 — SYSTEMS + CLOUD + CISCO PREP 🚀

WEEK 9 → SYSTEM PROGRAMMING

Learn:

• Processes vs Threads
• Multithreading
• Mutex
• Semaphore
• Race Conditions
• Deadlocks
• IPC
• Memory Management
• System Calls

Build:

**TCP Client–Server Application**

Client
↓
TCP
↓
Server
↓
Multiple Clients

WEEK 10 → SYSTEM DESIGN + CLOUD

Learn:

• Load Balancing
• Caching
• Replication
• Sharding
• Message Queues
• Rate Limiting
• Fault Tolerance
• Horizontal Scaling

Then learn:

• AWS basics
• EC2
• VPC
• IAM
• Docker
• Kubernetes basics

Resources:

System Design Primer →
[github.com/donnemartin/sy…](https://github.com/donnemartin/system-design-primer)

AWS →
[aws.amazon.com/training/](https://aws.amazon.com/training/)

Docker →
[docs.docker.com/get-started/](https://docs.docker.com/get-started/)

Kubernetes →
[kubernetes.io/docs/tutorials/](https://kubernetes.io/docs/tutorials/)

WEEK 11 → NETWORK AUTOMATION

Learn:

• Python
• REST APIs
• JSON
• YAML
• Ansible
• NETCONF
• RESTCONF
• YANG

Resource:

Cisco DevNet →
[developer.cisco.com](https://developer.cisco.com/)

Build:

Python
↓
RESTCONF / NETCONF
↓
Network Device
↓
Configuration

WEEK 12 → INTERVIEW PREPARATION 🎯

Revise:

• DSA
• Computer Networks
• OS
• DBMS
• OOP
• Linux
• System Design
• Projects

Practice questions like:

• What happens when you type [google.com](http://google.com)?
• TCP vs UDP?
• Explain TCP 3-way handshake.
• What is DNS?
• What is ARP?
• Router vs Switch?
• What is VLAN?
• How does subnetting work?
• OSPF vs BGP?
• What is NAT?
• Process vs Thread?
• What causes a deadlock?

PROJECTS TO BUILD

Don't fill your GitHub with basic CRUD apps.

Build 2–3 relevant projects:

**1. TCP Chat Application**

C++ / Python
+
Socket Programming
+
Multithreading

**2. Network Monitoring Tool**

• Ping hosts
• Check ports
• Track latency
• Detect failures
• Generate logs

**3. Network Automation Tool**

Python
+
RESTCONF / NETCONF
+
Network Configuration

FINAL TARGET 🎯

By the end of 3 months, you should have:

✓ 120–150 quality DSA problems
✓ Strong networking fundamentals
✓ Linux fundamentals
✓ Socket programming knowledge
✓ OS + DBMS revision
✓ System design basics
✓ Cloud fundamentals
✓ Network automation basics
✓ 2–3 relevant projects
✓ Cisco-specific interview preparation

Don't try to learn everything Cisco uses.

Build the **core engineering + networking foundation** first.

That's what will make your preparation different from a generic SDE roadmap.
